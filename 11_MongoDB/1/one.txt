=========================================================
MONGODB OVERVIEW
=========================================================

MongoDB:
    - NoSQL Database
    - Document Oriented Database
    - Schema-less Database
    - Stores Unstructured / Semi Structured Data
    - Data stored in BSON format
    - BSON = Binary JSON

Structure:

MongoDB
   |
   |-- Database
          |
          |-- Collection (Similar to Table)
                  |
                  |-- Document (Similar to Record)
                          |
                          |-- Field : Value


Example:

Database:
    Student

Collection:
    Details

Document:

{
    "name":"John",
    "age":21,
    "course":"Python"
}


WHY:
---------------------------------------------------------
- Flexible data model
- Faster development
- Handles large amount of data
- Easy horizontal scaling

=========================================================
INSERT DOCUMENT
=========================================================


MET:

insert_one()


SYN:

collection.insert_one(document)



USA:

{
"name":"Ram",
"age":25,
"city":"Bangalore"
}
)



RES:

One document inserted


---------------------------------------------------------


MET:

insert_many()


USA:

col.insert_many(
[
{
"name":"John",
"age":22
},
{
"name":"Sam",
"age":23
}
]
)



=========================================================
READ DOCUMENT
=========================================================


MET:

find_one()


SYN:

collection.find_one(query)


USA:

data = col.find_one()

print(data)



RES:

Returns first document


---------------------------------------------------------


MET:

find()


USA:

for data in col.find():
    print(data)



RES:

Returns all documents


---------------------------------------------------------


FILTER QUERY:


USA:

col.find(
{
"age":20
}
)



=========================================================
QUERY OPERATORS
=========================================================


Comparison Operators:


$gt  -> Greater Than

$lt  -> Less Than

$gte -> Greater Equal

$lte -> Less Equal

$eq  -> Equal

$ne  -> Not Equal


EXA:


col.find(
{
"age":
{
"$gt":18
}
}
)



=========================================================
LOGICAL OPERATORS
=========================================================


$and

$or

$not

$nor


EXA:

]
}

AGGREGATION
=========================================================


WHY:

Used for data processing and calculations.


MET:

aggregate()



Pipeline:

Document
   |
   |
Aggregation Stage
   |
   |
Result



Common Stages:

$match
$group
$sort
$limit
$project



EXA:


col.aggregate(
[
{
"$group":
{
"_id":"$city",
"count":
{
"$sum":1
}
}
}
]
)

COMMON PYTHON MONGODB FLOW
=========================================================


[STE]


1. Install pymongo

2. Import MongoClient

3. Connect MongoDB Server

4. Select Database

5. Select Collection

6. Perform CRUD Operations

7. Close Connection



USA:


from pymongo import MongoClient


client = MongoClient(
"mongodb://localhost:27017/"
)


db = client["company"]

collection = db["employee"]


collection.insert_one(
{
"name":"Tom",
"salary":50000
}
)


for emp in collection.find():
    print(emp)
