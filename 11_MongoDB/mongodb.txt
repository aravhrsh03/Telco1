MongoDB:
    - No SQL database
    - No SCHEMA
    - Stores the Unstructed Data
    - it has collections (Table)
    - each collections have documents (Record)

    [Note: to show the database in compass you should have the collection with atleast a document]

    - stores as BSON - Binary JSON

MongoSHELL
    - [COMMAND] mongosh
    - it provides the mongodb terminal works in the terminal itself

    [USA]
        from pymongo import MongoClient

        url = "mongodb://localhost:27017/"
        client = MongoClient(url)

        print(client.list_database_names()) # provides the available db names
