RDD - Resilient Distributed Dataset

	- RDD = Resilient Distributed Dataset
	- Distributed, immutable, fault-tolerant collection
	- Data divided into partitions and processed in parallel
	- Supports lazy evaluation and lineage
	- Accessed using SparkContext

	[RESILIENT]

		- Fault tolerant
		- Lost partitions recreated using lineage

	[DISTRIBUTED]

		- Data divided into partitions
		- Partitions processed in parallel

	[DATASET]

		- Collection of data
		- Can contain any Python object

	[CREATE]

		- parallelize() creates RDD from Python collection

		sc = spark.sparkContext

		data = [10, 20, 30, 40, 50]

		rdd = sc.parallelize(data)

	[PARTITIONS]

		- Data divided into partitions
		- Number of partitions can be specified
		- Default partition size is 8 in pyspark,
		rdd = sc.parallelize(data, 2)

		rdd.getNumPartitions()

	[TRANSFORMATION]

		- Creates new RDD
		- Lazy execution
		- Examples: map(), filter(), flatMap(), reduceByKey()

		rdd2 = rdd.map(lambda x: x * 2)

	[MAP]

		- Applies function to every element
		- One input -> one output

		rdd.map(lambda x: x * 2)

	[FILTER]

		- Selects elements matching condition

		rdd.filter(lambda x: x > 30)

	[FLAT MAP]

		- map() + flatten
		- One input -> zero or multiple outputs

		rdd.flatMap(lambda x: x.split(" "))

	[REDUCE]

		- Combines all elements into one value

		rdd.reduce(lambda x, y: x + y)

	[REDUCE BY KEY]

		- Combines values having same key

		rdd.reduceByKey(lambda x, y: x + y)

	[KEY-VALUE]

		- Elements can be (key, value)
		- Used for grouping and aggregation

		rdd = sc.parallelize([
		("A", 10),
		("B", 20),
		("A", 30)
		])

	[ACTION]

		- Triggers execution
		- Examples: collect(), count(), first(), reduce()

		rdd2 = rdd.map(lambda x: x * 2)

		rdd2.collect()

	[COLLECT]

		- Returns all data to driver
		- Avoid for very large data

		rdd.collect()

	[COUNT]

		- Returns number of elements

		rdd.count()

	[LAZY EVALUATION]

		- Transformations are not executed immediately
		- Execution starts when action is called

		rdd2 = rdd.filter(lambda x: x > 20)

		rdd2.collect()

	[LINEAGE]

		- Records transformation sequence
		- Used to recover lost partitions

		rdd2 = rdd.map(lambda x: x * 2)
		rdd3 = rdd2.filter(lambda x: x > 5)

	[CACHE]

		- Keeps RDD for reuse
		- Avoids recomputation

		rdd.cache()

	[PERSIST]

		- Stores RDD using storage level

		from pyspark import StorageLevel

		rdd.persist(StorageLevel.MEMORY_AND_DISK)

	[UNPERSIST]

		- Removes cached/persisted RDD

		rdd.unpersist()

	[RDD VS DATAFRAME]

		- RDD -> low-level, unstructured, more control
		- DataFrame -> high-level, structured, optimized
		- DataFrame preferred for most structured-data processing

		rdd = sc.parallelize([(1, "John", 25)])

		df = spark.createDataFrame(
			rdd,
			["id", "name", "age"]
		)

	RDD Processing pipeline = SparkSession -> context -> RDD creation -> transform -> caching -> actions
		from pyspark.sql import SparkSession

		spark = SparkSession.builder
		.appName("RDDExample")
		.master("local[*]")
		.getOrCreate()

		sc = spark.sparkContext

		data = [10, 20, 30, 40, 50]

		rdd = sc.parallelize(data)

		rdd2 = rdd.map(lambda x: x * 2)

		rdd2.cache()

		print(rdd2.collect())

		print(rdd2.count())

		spark.stop()
	
	REPARTITION:

		- Changes number of RDD partitions
		- Can increase or decrease partitions
		- Causes shuffle
		- Returns new RDD

		rdd2 = rdd.repartition(4)

		[GET PARTITIONS]

			- Returns partition count

			rdd.getNumPartitions()

		[EXAMPLE]

			rdd = sc.parallelize([10, 20, 30, 40], 2)

			print(rdd.getNumPartitions())

			rdd2 = rdd.repartition(4)

			print(rdd2.getNumPartitions())

			rdd3 = rdd2.coalesce(2)

			print(rdd3.getNumPartitions())

		[REPARTITION VS COALESCE]

			- repartition() -> increase/decrease partitions + shuffle
			- coalesce() -> mainly decrease partitions + less shuffle

				2 partitions
					↓
				repartition(4)
					↓
				4 partitions
					↓
				coalesce(2)
					↓
				2 partitions

	[STRUCTTYPE]

		- StructType is used to define a DataFrame schema
		- StructField defines each column
		- Common types: StringType(), IntegerType(), DoubleType()
		- Used when converting an RDD into a DataFrame

	[STRUCT FIELD]

Conditional Aggregation

	[USA]
		from pyspark.sql.functions import *

		df.agg(
			sum(when(col("salary") > 70000, col("salary"))).alias("high_salary_sum"),
			avg(when(col("salary") > 70000, col("salary"))).alias("high_salary_avg"),
			count(when(col("salary") > 70000, 1)).alias("high_salary_count")
		)

	[FUN]:

		when(condition, value)                    → Apply condition
		sum(when(...))                            → Conditional sum
		avg(when(...))                            → Conditional average
		count(when(...))                          → Conditional count
		groupBy(...).agg(...)                     → Conditional aggregation per group

	[EXA]:

		df.groupBy("dept").agg(
			sum(when(col("salary") > 70000, col("salary"))).alias("high_salary")
		)

		→ Calculates the total salary > 70,000 for each department.

Joins

[USA]
	from pyspark.sql import SparkSession

	spark = (
		SparkSession.builder
		.master("local[*]")
		.appName("JoinPractice")
		.getOrCreate()
	)

	# Employee DataFrame
	employees_data = [
		(1, "Alice", 101, 75000),
		(2, "Bob", 102, 65000),
		(3, "Charlie", 103, 80000),
		(4, "David", 104, 70000),
		(5, "Eve", 105, 60000)
	]

	employees_columns = ["emp_id", "name", "dept_id", "salary"]

	employees_df = spark.createDataFrame(
		employees_data,
		employees_columns
	)


	# Department DataFrame
	departments_data = [
		(101, "IT"),
		(102, "HR"),
		(103, "Finance"),
		(106, "Marketing")
	]

	departments_columns = ["dept_id", "dept_name"]

	departments_df = spark.createDataFrame(
		departments_data,
		departments_columns
	)


	employees_df.show()
	departments_df.show()

[MET]
	# INNER JOIN
	# → Matching rows only | LEFT + RIGHT columns
	employees_df.join(departments_df, "dept_id", "inner").show()

	# LEFT JOIN
	# → All LEFT rows + matching RIGHT rows | LEFT + RIGHT columns
	employees_df.join(departments_df, "dept_id", "left").show()

	# RIGHT JOIN
	# → All RIGHT rows + matching LEFT rows | LEFT + RIGHT columns
	employees_df.join(departments_df, "dept_id", "right").show()

	# FULL JOIN
	# → All rows from LEFT + RIGHT | LEFT + RIGHT columns
	employees_df.join(departments_df, "dept_id", "full").show()

	# LEFT SEMI JOIN
	# → Matching LEFT rows only | LEFT columns only
	employees_df.join(departments_df, "dept_id", "left_semi").show()

	# LEFT ANTI JOIN
	# → Non-matching LEFT rows only | LEFT columns only
	employees_df.join(departments_df, "dept_id", "left_anti").show()

	# CROSS JOIN
	# → Every LEFT row × every RIGHT row | LEFT + RIGHT columns | No condition
	employees_df.crossJoin(departments_df).show()

	# CONDITION JOIN
	# → Join using a custom condition/expression | LEFT + RIGHT columns
	employees_df.join(
		departments_df,
		employees_df.dept_id == departments_df.dept_id,
		"inner"
	).show()

	# BROADCAST JOIN
	# → Broadcast small DataFrame to workers | Avoids large shuffle
	from pyspark.sql.functions import broadcast

	employees_df.join(
		broadcast(departments_df),
		"dept_id",
		"inner"
	).show()

		Normal Join:
		Large DF ←→ Large DF
				↓
			Shuffle

		Broadcast Join:
		Small DF → copied to workers
		Large DF ←→ Small DF
				↓
		Less shuffle

	BROADCAST JOIN

		Small table
			↓
		Copy to every worker
			↓
		Big table stays distributed
			↓
		Join locally
			↓
		Less shuffle → Faster

PERSIST() — PySpark

	[PERSIST]
		→ Stores a DataFrame's computed data for reuse.
		→ Avoids recomputing the same DataFrame repeatedly.

	[WHY]
		→ Use when the same DataFrame is used multiple times.

	[LIB]
		→ from pyspark import StorageLevel

	[SYN]
		→ df.persist()

	[USA]
		df2 = df.filter(df.salary > 70000)

		df2.persist()

		df2.count()
		df2.show()

		→ First action computes and caches df2.
		→ Later actions can reuse the persisted data.

	[STORAGE]
		→ Default: MEMORY_AND_DISK

	[EXA]
		df.persist(StorageLevel.MEMORY_AND_DISK)

	[UNPERSIST]
		→ Remove DataFrame from cache/storage.

		df2.unpersist()

	[DIFF]
		cache()   → Shortcut for persist(MEMORY_AND_DISK)
		persist() → Allows choosing storage level

	[USC]
		→ Reusing the same DataFrame multiple times.
		→ Expensive transformations.
		→ Iterative processing.

	[QUICK MEMORY]
		persist() → Compute once → Store → Reuse
		unpersist() → Remove stored data

ORC = Optimized Row Columnar

	→ Columnar file format used in Hadoop/Spark
	→ Stores data column-wise, not row-wise
	→ Faster for reading only required columns
	→ Supports compression → saves storage
	→ Supports predicate pushdown → reads only relevant data
	→ Commonly used with Hive and Spark

	Normal row storage:
		Row 1 → id, name, dept, salary
		Row 2 → id, name, dept, salary

		ORC:
		id     → 1, 2, 3, 4
		name   → Alice, Bob, ...
		dept   → IT, HR, ...
		salary → 75000, 65000, ...
	
	ORC → Columnar + Compressed + Fast reads

	[US]
		df.write.orc("employees.orc")

		df = spark.read.orc("employees.orc")

CTE = Common Table Expression
    → Named temporary query result using WITH.

	[WHY]
		→ Organize complex SQL into smaller steps.

			SELECT ...
		)
		SELECT ...
		FROM cte_name

			WITH high_salary AS (
				SELECT *
				FROM emp_view
				WHERE salary > 70000
			)
			SELECT *
			FROM high_salary
		""").show()

	[RES]
		→ Employees with salary > 70000.


CTE + AGGREGATION

UDF = User Defined Function

	[UDF]
		→ Custom function created by the user for logic not available
		in built-in Spark functions.

	[WHY]
		→ Apply custom Python logic to DataFrame columns.

	[LIB]
		→ from pyspark.sql.functions import udf
		→ from pyspark.sql.types import StringType

	[SYN]
		→ udf(python_function, return_type)

	[USA]
		from pyspark.sql.functions import udf, col
		from pyspark.sql.types import StringType

		def get_grade(salary):
			return "High" if salary >= 70000 else "Low"

		grade_udf = udf(get_grade, StringType())

		df.withColumn(
			"grade",
			grade_udf(col("salary"))
		).show()

	[RES]
		→ Creates a new "grade" column based on salary.

	[PAR]
		→ python_function → Custom Python function
		→ return_type    → UDF output data type

	[OPT]
		→ Prefer built-in functions such as:
			when()
			concat()
			regexp_replace()
			upper()
			lower()
		whenever possible.

	[ANE]
		from pyspark.sql.functions import udf, col
		from pyspark.sql.types import IntegerType

		def add_bonus(salary):
			return salary + 5000

		bonus_udf = udf(add_bonus, IntegerType())

		df.withColumn(
			"new_salary",
			bonus_udf(col("salary"))
		).show()

JDBC + PySpark
    → Connect PySpark with an external database using JDBC.

	[FLOW]
		PySpark → JVM → Spark → JDBC → Database

	[LIB]
		from pyspark.sql import SparkSession

	[STE]
		1. Create SparkSession
		2. Define JDBC URL
		3. Define connection properties
		4. Read table into DataFrame

	[USA]

		spark = (
			SparkSession.builder
			.master("local[*]")
			.appName("JDBCExample")
			.getOrCreate()
		)

		url = "jdbc:mysql://localhost:3306/company"

		properties = {
			"user": "root",
			"password": "password",
			"driver": "com.mysql.cj.jdbc.Driver"
		}

		df = (
			spark.read
			.jdbc(
				url=url,
				table="employees",
				properties=properties
			)
		)

		df.show()

	[PAR]

		table      → Database table name
		properties → Connection details

			password → Database password
			driver   → JDBC driver

	[SYN]

			table,
			properties
		)

	[RES]

	[QUICK MEMORY]
		Session → URL → Properties → Read → DataFrame

			UPDATE → SQL UPDATE
