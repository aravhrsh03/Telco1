	CPU Bound
	
	- Heavy calculations (CPU does most of the work)
	- Uses CPU continuously instead of waiting
	- Performance depends on CPU speed
	- Uses multiple CPU cores for better performance
	- In Python, Multithreading does not improve CPU-bound tasks because of GIL
	- Best solution is Multiprocessing (separate processes)
	

	[WHY]
	- To perform heavy calculations faster
	- To use multiple CPU cores
	- To avoid GIL limitation
	- To improve execution speed of CPU-intensive programs

	[EXA]
	- Prime number calculation
	- Matrix multiplication
	- Image processing
	- Video rendering
	- Machine Learning training
	- Password hashing
	- Scientific calculations
	- Data compression

	[LIB]
	multiprocessing

	[USA]
	from multiprocessing import Process

	
	def worker():
		total = 0
		for i in range(10000000):
			total += i
		print("Calculation Finished")

	p = Process(target=worker)
	p.start()
	p.join()
	

	[PAR]
	Process(
	target=function_name,
	args=(arg1, arg2),
	name="ProcessName",
	daemon=False
	)

	[SYN]
	from multiprocessing import Process

	
	p = Process(target=function_name, args=(arguments,))
	p.start()
	p.join()
	

	[MET]
	.start()
	- Starts the process
	- Executes the target function

	
	.join()
		- It is not mandatory
		- Without this, the main program continues executing
		- We use it to wait until the current process finishes

	.is_alive()
		- Returns True if the process is running
		- Returns False if the process has finished

	.terminate()
		- Stops the process immediately

	.close()
		- Releases process resources (used in some multiprocessing objects)
	

	[FUN]
	Process()
	- Creates a new process

	
	start()
		- Starts execution

	join()
		- Waits for process completion

	is_alive()
		- Checks whether process is running

	terminate()
		- Stops the process
	

	[DAM]
	p.pid
	- Returns Process ID

	
	p.name
		- Returns process name

	p.daemon
		- Returns daemon status
	

	[ALI]
	- CPU Intensive Task
	- Compute Bound
	- Processing Bound

	[RES]
	- Heavy calculations execute faster
	- Multiple CPU cores work together
	- Better performance for CPU-intensive programs
	- Main process waits when join() is used

	[OPT]
	args
	- Optional
	- Passes arguments to the function

	
	name
		- Optional
		- Gives a custom process name

	daemon
		- Optional
		- Runs process in background
	

	[CAT]
	- Cannot efficiently use Multithreading for CPU-bound tasks in Python
	- Cannot achieve true parallel execution using threads because of GIL
	- Not suitable for waiting tasks like file reading or downloading

	def square():

	p = Process(target=square)

	REGULAR EXPRESSION (Regex)


	- Pattern used to search, match, extract, and replace text
	- Python library: `re`


	[LIB]
		re

		[USA]
		import re

		result = re.search(r"\d+", "Age 25")

		print(result.group())

	[RES]
		25

	[WHY]
		- Data validation
		- Text searching
		- Data extraction
		- Text replacement

	BASIC PATTERNS

		\d
		- Digit (0-9)

		\D
		- Non-digit

		\w
		- Word (a-z, A-Z, 0-9, _)

		\W
		- Non-word

		\s
		- Space

		\S
		- Non-space

		.
		- Any character

	CHARACTER SET

		[abc]
		- Match a/b/c

		[a-z]
		- Lowercase

		[A-Z]
		- Uppercase

		[0-9]
		- Numbers

		[^0-9]
		- Except numbers

	QUANTIFIERS

		* * 0 or more

		- - 1 or more

		?
		- Optional

		{n}
		- Exactly n times

		{n,m}
		- Range

	SYMBOLS

		- Start

		$
		- End

		|
		- OR

		()
		- Group

	METHODS

	[MET]

		re.match()
		- Match from beginning

		re.search()
		- Find first match

		re.findall()
		- Find all matches

		re.sub()
		- Replace text

		re.split()
		- Split string

	[SYN]

		re.method(pattern, string)
