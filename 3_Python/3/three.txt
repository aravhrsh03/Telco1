  -> ZipLongest = combines the two set/list/tuple like a pair

  -> FUNCTIONS - Functions are individual declared calling by its name
	[Note: Overloading is allowed, not overriding in python]
	[So each function have unique function]

	- Able to have one return with multiple values (comma seperated)
	- Positional Arguments should be at the last

  -> function with / - before the / it is positional arguments, after it is combinations
	[USA]
		def posi(a1, b1, /):
			print(a1, b1)
	
		print(posi(1, 2)) # before only positional, should be like posi(a1 = 1, b1 = 2) since this is keyword argument

		def posi2(a1, b1, / x, y):
			print(a1 + b1)

		print(posi2(1, 2, x = 1, y = 2))

  -> function with * - before the * it should be positional argument, after it should be keyword.

	[USA]
		def keyw(name, *, city):
			print(name, city)
		keyw("madhan", city="chennai") # city should be keyword

	- *a parameter can accept many values

	[USA]
		def fun(*a):
			print(sum(a))
	
		fun(1, 2, 3, 4)

	- **kwargs parameter can accept many values as key and value pair
	
	[USA]
		def fun(**kwargs):
			print(kwargs)
	
		fun(key1=1, key2=2)

  -> lambda function - anonymous function (it doesn't have a specific name it have the storage function, function stored in a variable)

	[USA]

  -> Decorator - it is a function which wrap another function
	[USA]
		def deco(func):
			def wrap():
				print("Before")
				func()
				print("After")
			return wrap
	
		@deco
		def outer():
			print("Outer")
	
		outer()
