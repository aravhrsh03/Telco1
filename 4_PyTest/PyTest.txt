 ABBREVIATION:
	-> LIB = LIBRARY
	-> USA = USAGE [example code]
	-> PAR = PARAMETERS
	-> SYN = syntax
	-> WHY = Why this is used
	-> EXA = Example
	-> MET = METHODS
	-> CAT = Cannot have it
	-> ALI = Alias
	-> RES = Expected Result
	-> OPT = Optionalx
	-> ANE = Another Example
	-> FUN = Functions used
	-> DAM = Data Members
	-> TYS = Types
	-> VER = Python version
	-> USC = Use Cases

FIXTURE

    - Used to share common setup code
    - Runs before the test function
    - Avoids duplicate code
    - Created using `@pytest.fixture`

    [LIB]

        import pytest

    [USA]

        import pytest

        @pytest.fixture
        def data():
            return [1, 2, 3]

        def test_length(data):
            assert len(data) == 3


    [WHY]

        - Reuse setup code
        - Cleaner tests
        - Reduce code duplication

    [SYN]

        @pytest.fixture
        def fixture_name():
            return value

        def test_name(fixture_name):
            assert ...

    [USC]

        - Database connection
        - Test data
        - File setup
        - Object creation

    REMEMBER

        @pytest.fixture
            ↓
        Create Fixture
            ↓
        Pass as Function Argument
            ↓
        Use in Test
