JavaScript

    - JavaScript is a high-level, scripting, and programming language.
    - It is used for both frontend (browser) and backend development.
    - Backend JavaScript runs using Node.js.
    - JavaScript works in all modern browsers (Chrome, Edge, Firefox, Brave, Safari, etc.) because they have built-in JavaScript engines.
    - You can write JavaScript in the browser console. This is browser JavaScript, not Node.js.
    - Node.js is a runtime that allows JavaScript to run outside the browser.
    - Browsers do not need Node.js to run JavaScript.
    - JavaScript is a Single Threaded Project

    Execution Flow:
    Browser:
    JavaScript → Browser JavaScript Engine (e.g., V8) → Machine Code

    Backend:
    JavaScript → Node.js (uses V8 Engine) → Machine Code

Node

    - npm - node package manager (with this only I can create axios, express)
    - npx is a command that temporarily runs npm packages, so you don't have to install them globally first.

npm init

    * Creates a package.json file for a Node.js project.
    * Stores project information like name, version, dependencies, and scripts.
    * Used when starting a new Node.js project.
    * npm init asks questions to configure the project.
    * npm init -y creates package.json with default settings automatically.

    Memory tip:
    npm init = Initialize a Node.js project.

Tilde (~) and Caret (^) in npm versions:

    Tilde (~):

    * Allows patch updates only.
    * Keeps major and minor versions fixed.
    * Example: ~1.2.3 allows 1.2.4, 1.2.9.
    * Does not allow 1.3.0 or 2.0.0.
    * Used for bug fixes only.

    Caret (^):

    * Allows minor and patch updates.
    * Keeps the major version fixed.
    * Example: ^1.2.3 allows 1.2.4, 1.3.0, 1.9.9.
    * Does not allow 2.0.0.
    * Used for new features and bug fixes.

    Memory:
    ~ = Patch only (1.2.x)
    ^ = Minor + Patch (1.x.x)

process object in Node.js

    process:

    * Built-in Node.js object.
    * Gives information and control about the running program.

    [MET]
        process.pid:

        * Returns the current process ID.
        * Example: console.log(process.pid)

        process.cwd():

        * Returns the current working directory.
        * Example: console.log(process.cwd())

        process.version:

        * Returns the Node.js version.
        * Example: console.log(process.version)

        process.platform:

        * Returns the operating system platform.
        * Example: console.log(process.platform)

        process.argv:

        * Returns command-line arguments.
        * Example: console.log(process.argv)

        process.env:

        * Accesses environment variables.
        * Example: console.log(process.env)

        process.exit():

        * Stops the Node.js process.
        * Example: process.exit()

        process.memoryUsage():

        * Shows memory usage of the application.
        * Example: console.log(process.memoryUsage())

        process.uptime():

        * Shows how long the process has been running.
        * Example: console.log(process.uptime())

    Memory:
    process = information and control of the current Node.js program.

Buffer in Node.js 

    Buffer is used to store and handle binary data directly in memory.
    Node.js uses Buffer when working with files, images, videos, and network data.
    It handles data that cannot be represented as normal text.


-> ES5 Export = exports data using CommonJS module system
   [SYN]
      module.exports = <value>

   [USA]
      // math.js
      function add(a,b){
         return a+b
      }
      module.exports = add


-> ES5 Import = imports module using require()
   [SYN]
      require(<module-path>)

   [USA]
      const add = require("./math")
      add(2,3)


-> ES5 Multiple Export
   [SYN]
      module.exports = { <value1>, <value2> }

   [USA]
      module.exports = {
         add,
         subtract
      }


-> ES6 Export = exports data using ES module system
   [SYN]
      export <value>

   [TYS]
      1. Named Export
      2. Default Export


-> ES6 Named Export = export multiple values with name
   [SYN]
      export { <value-name> }

   [USA]
      // math.js
      export function add(a,b){
         return a+b
      }


-> ES6 Named Import = import using same exported name
   [SYN]
      import { <value-name> } from <module-path>

   [USA]
      import { add } from "./math.js"


-> ES6 Default Export = export single main value
   [SYN]
      export default <value>

   [USA]
      export default function add(a,b){
         return a+b
      }


-> ES6 Default Import = import without curly braces
   [SYN]
      import <any-name> from <module-path>

   [USA]
      import add from "./math.js"


-> CommonJS vs ES Module
   [ES5]
      Export = module.exports
      Import = require()

   [ES6]
      Export = export
      Import = import


-> WHY
   ES5 = older Node.js module system
   ES6 = modern JavaScript module system

-> VER
   ES5 = CommonJS
   ES6 = ES Modules (ESM)



File Handling = Used to create, read, update, and delete files in Node.js

      [LIB]
         fs = File System module
         fs/promises = Promise-based file system module


   -> fs/promises = Provides file methods using Promise

      [USA]
         import fs from "fs/promises";


   -> writeFile() = Creates a file or overwrites existing file

      [SYN]
         fs.writeFile(<file-name>, <data>)

      [USA]
         fs.writeFile("f1.txt", "new file created")
         .then(() => {
            console.log("file created...")
         })
         .catch((err) => {
            console.log(err)
         })


   -> Promise Methods:

      .then() = Executes when Promise is resolved (success)

      .catch() = Executes when Promise is rejected (error)

      [SYN]
         <promise>
         .then(<success-function>)
         .catch(<error-function>)


   -> async/await Method:

      [USA]
         async function createFile() {
            await fs.writeFile("f1.txt", "new file created");
            console.log("file created...")
         }

         createFile()


   -> try/catch = Handles errors with async/await

      [USA]
         async function createFile() {
            try {
               await fs.writeFile("f1.txt", "new file created");
               console.log("file created...")
            }
            catch(err) {
               console.log(err)
            }
         }


   -> Common fs Methods:

      [MET]
         writeFile()  = Create/write file
         readFile()   = Read file content
         appendFile() = Add content to file
         rename()     = Rename file
         unlink()     = Delete file
         mkdir()      = Create folder
         access()     = File existence


   -> WHY
      fs/promises supports non-blocking file operations using Promises.

   -> MEMORY:
      .then()  = Success
      .catch() = Error
      await    = Wait for Promise result



-> HTTP Module = Creates HTTP servers and handles client requests in Node.js

      [LIB]
         http = Built-in Node.js module

      [USA]
         import http from "http";

         const server = http.createServer((request, response) => {
            response.write("Welcome to node js server");
            response.end();
         });

         server.listen(3000);

         console.log("server working");


   -> createServer() = Creates HTTP server

      [SYN]
         http.createServer((request, response) => {
            <response>
         })


   -> request = Contains client request information

      [DAM]
         request.url    = Requested URL path
         request.method = HTTP method (GET, POST, etc.)
         request.headers = Request headers


   -> response = Sends data back to client

      [FUN]

         response.write()
            = Writes response data

         response.end()
            = Ends the response


   -> response.setHeader() = Sets response headers

      [SYN]
         response.setHeader(<header-name>, <value>)

      [USA]
         response.setHeader("Content-Type", "text/html");


   -> Common Headers:

      Content-Type
         = Defines response data type

         Example:
         "text/html"
         "application/json"


      Access-Control-Allow-Origin
         = Allows CORS requests


      Cache-Control
         = Controls browser caching


   -> response.writeHead() = Sets status code and headers together

      [SYN]
         response.writeHead(<status-code>, {
            <headers>
         })

      [USA]
         response.writeHead(200, {
            "Content-Type": "application/json"
         });


   -> HTTP Status Codes:

      200 = Success
      201 = Created
      400 = Bad Request
      404 = Not Found
      500 = Server Error


   -> request methods:

      GET
         = Get data

      POST
         = Send data

      PUT
         = Update data

      DELETE
         = Remove data


   -> server.listen() = Starts server on given port

      [SYN]
         server.listen(<port-number>)

      [USA]
         server.listen(3000)


   -> JSON Response:

      [USA]
         response.setHeader("Content-Type","application/json");

         response.end(JSON.stringify({
            message:"Hello"
         }));


   -> WHY
      HTTP module is used to create web servers without external frameworks.

   -> MEMORY:

      createServer() = Create server
      request       = Client data
      response      = Server data
      setHeader()   = Add response headers
      listen()      = Start server
