EDA – EXPLORATORY DATA ANALYSIS
===============================

    [WHY]
        Exploratory Data Analysis (EDA) is the process of
        understanding, cleaning, and analyzing a dataset
        before building any Machine Learning model.

    [USC]
        - Understand the dataset
        - Detect errors
        - Clean data
        - Discover hidden patterns
        - Find relationships between variables
        - Generate business insights
        - Prepare data for Machine Learning

    [MET]
        - Data Inspection
        - Data Cleaning
        - Statistical Analysis
        - Data Visualization
        - Feature Understanding
        - Correlation Analysis


    IMPORT LIBRARIES
    ================

        [ALI]
            import pandas as pd
            import numpy as np
            import matplotlib.pyplot as plt
            import seaborn as sns


    LOAD DATASET
    ============

        [USA]
            df = pd.read_csv("data.csv")

        [RES]
            Loads the dataset into a Pandas DataFrame.


    DATA INSPECTION
    ===============

    1. View First Records
    ---------------------

        [WHY]
            Displays the first few rows.

        [USA]
            df.head()

    2. View Last Records
    --------------------

        [WHY]

        [USA]
            df.tail()

    3. Dataset Shape
    ----------------

        [WHY]

        [USA]

    4. Dataset Information
    ----------------------

    ---------------

    6. Data Types
    -------------

            Displays data type of every column.

        [USA]

    DATA CLEANING
    =============

    1. Missing Values
    -----------------

        [WHY]
            Finds missing (NULL/NaN) values.

        [USA]
            df.isnull()

        Count missing values:

            df.isnull().sum()

        Remove missing values:

            df.dropna()

        Fill missing values:

            df.fillna(0)

            df.fillna(df.mean(numeric_only=True))


    2. Duplicate Values
    -------------------

        [WHY]
            Finds duplicate records.

        [USA]
            df.duplicated()

        Count duplicates:

            df.duplicated().sum()

        Remove duplicates:

            df.drop_duplicates()


    3. Rename Columns
    -----------------

        [WHY]
            Changes column names.

        [USA]
            df.rename(
                columns={"Old":"New"},
                inplace=True
            )


    4. Change Data Type
    -------------------

        [WHY]
            Converts one data type into another.

        [USA]
            df["Age"] = df["Age"].astype(int)


    STATISTICAL SUMMARY
    ===================

        [WHY]
            Displays summary statistics for
            numerical columns.

        [USA]
            df.describe()

        [RES]
            Shows:
                - Count
                - Mean
                - Standard Deviation
                - Minimum
                - 25%
                - 50% (Median)
                - 75%
                - Maximum

        Include all columns:

            df.describe(include="all")

    =====================

    Correlation
    -----------

        [WHY]
            Measures relationship between
            numerical variables.

        [USA]

DATA INGESTION
==============

    [WHY]
        Data Ingestion is the process of importing,
        collecting, and transferring data from one
        or more sources into a storage system or
        processing platform.

    [USC]
        - Data Warehouse
        - Data Lake
        - ETL Pipeline
        - Machine Learning Pipeline

    [TYS]

        1. Batch Ingestion
            - Data is collected at scheduled intervals.
            - Suitable for historical data.
            - Example:
                Daily sales report.

        2. Real-Time (Streaming) Ingestion
            - Data arrives continuously.
            - Suitable for live applications.
            - Example:
                Stock market data, IoT sensors.


TYPES OF DATA SOURCES
=====================

    [TYS]

        1. Internal Data Sources
            - Company databases
            - ERP Systems
            - CRM Systems
            - Sales Records
            - Employee Records

        2. External Data Sources
            - Government datasets
            - Public APIs
            - Social Media
            - Third-party vendors
            - Market research reports

        3. Structured Data
            - Organized in rows and columns.
            - Stored in SQL databases.
            - Example:
                MySQL, PostgreSQL

        4. Semi-Structured Data
            - Has some structure but no fixed schema.
            - Example:
                JSON, XML, CSV

        5. Unstructured Data
            - No predefined format.
            - Example:
                Images, Videos, Audio, Emails, PDFs


COMMON DATA SOURCES
===================

    [MET]
        - SQL Databases
        - NoSQL Databases
        - CSV Files
        - Excel Files
        - JSON Files
        - XML Files
        - APIs
        - Cloud Storage
        - IoT Devices
        - Social Media
        - Log Files


QUICK DIFFERENCE
================

    Data Sourcing
        -> Finding and collecting data.

    Data Ingestion
        -> Moving collected data into a system
           for storage or processing.

INSERT RECORDS
==============

    [USA]

            (2,"Alice","Chicago"),
            (3,"David","Boston")
        ]

        products = [
            (101,"Laptop",850),
            (102,"Mouse",20),
            (103,"Keyboard",40)
        ]

        sales = [
            (1,1,101,1,"2025-01-01"),
            (2,2,102,2,"2025-01-03"),
            (3,1,103,1,"2025-01-05")
        ]

        cur.executemany(
            "INSERT INTO Customer VALUES(?,?,?)",
            customers
        )

        cur.executemany(
            "INSERT INTO Product VALUES(?,?,?)",
            products
        )

        cur.executemany(
            "INSERT INTO Sales VALUES(?,?,?,?,?)",
            sales
        )

        conn.commit()

MERGING TABLES USING PANDAS
===========================

Customer + Sales
----------------

    [USA]

        merge1 = pd.merge(
            customer_df,

            on="customer_id",
            how="inner"
        )

Sales + Product
---------------

    [USA]

        final_df = pd.merge(
            merge1,
            product_df,
            on="product_id",
            how="inner"
        )

    [RES]
        Final DataFrame contains

            Customer
                +
            Sales
                +
            Product


MERGE TYPES
===========

    [TYS]

        inner
            Returns matching records only.

        left
            Returns all rows from left table.

        right
            Returns all rows from right table.

        outer
            Returns all records from both tables.

KEY POINTS
==========

    • sqlite3 creates a local file-based database.
    • connect() opens or creates the database.
    • cursor() executes SQL queries.
    • executemany() inserts multiple records.
    • commit() permanently saves changes.
    • pd.read_sql() loads SQL tables into DataFrames.
    • pd.merge() joins multiple DataFrames.
    • EDA helps understand, clean, and analyze data.
    • Always close the connection using conn.close().
